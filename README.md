# Higgsfield Faceless Channel

One plugin for running a faceless video channel on Higgsfield.

| Skill | Use it for |
|---|---|
| higgsfield-faceless-script | Research and write the script and timed scene plan. Arabic scripts are delivered fully vocalized (tashkeel). |
| higgsfield-seedance-prompts | Turn scenes into cinematic Seedance prompts. The user chooses the video model and resolution (Seedance 2.5 at 1080p is the default). |
| higgsfield-faceless-production | Produce the video: narration, music, sound effects, scenes, captions and editing. The user chooses the video, speech, music and sound-effect models, with prices shown first. |
| higgsfield-youtube-packaging | Three thumbnail-and-title options, descriptions and test plans. |

Requires the Higgsfield connector.
